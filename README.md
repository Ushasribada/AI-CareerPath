# Backend datasets

Copy these existing project datasets from your Colab session into the matching folders before deploying:

resume_dataset/
- training_data.csv
- skills_list.csv
- job_roles.csv

job_market_dataset/
- job_description.csv
- job_postings.csv (optional for the current API)

The current production API uses the first three resume files and `job_description.csv`.
Do not upload private candidate resumes or credentials to GitHub.
